# Changelog

## 0.2.0 — 2026-07-06

**Team**
- 5 new roles: `security-expert` (threat models + audits, attack-path-required findings), `api-designer` (contracts so backend+frontend build in parallel), `devops-engineer` (CI/CD, containers, IaC), `performance-engineer` ("no measurement, no finding"), `data-migration-engineer` (ETL with mandatory reconciliation). Team is now 14 roles.
- Ponytail discipline (github.com/DietrichGebert/ponytail) threaded through every role, tailored per craft: tech-lead plans at the lowest ladder rung, implementers climb it, code-reviewer accepts `ponytail:`-marked shortcuts but flags unmarked ones on money/security paths, doc-keeper harvests the debt, security-expert allows no `ponytail:` excuse for vulnerabilities.

**Activation & skills**
- SessionStart hook: announces the team + brief in any briefed project, lists per-area overrides, warns when the brief looks stale (>30 commits since its date). Silent in non-briefed projects.
- `/dev-team:team-review` — standalone parallel code-reviewer + security-expert on the current diff, one merged verdict.
- `/dev-team:team-standup` — read-only digest: pending decisions, recent work, ponytail debt, open questions.

**Brief**
- New template sections: Security, API, Performance, Deployment; Legacy extended with migration policy.
- Monorepo support: `.devteam/<area>.md` overrides (only the differing sections) win over the root brief for their area; all agents read them.

**Infrastructure**
- `sync.sh --check` + GitHub Actions workflow: CI fails when generated Codex/Copilot files drift from `agents/` or are hand-edited.
- Repo is now a git repository.

**Considered and skipped (deliberately)**
- PreToolUse hooks to hard-enforce role boundaries — hooks can't reliably identify the calling subagent; prompts + reviewer cover it. Revisit if the harness exposes agent identity to hooks.
- Formal JSON handoff schema between agents — prose reports work; config for a value that doesn't change.
- Team benchmark/eval harness — premature until the team has real mileage.
- `team-help` skill — the README covers it.
